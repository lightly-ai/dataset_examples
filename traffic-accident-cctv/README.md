# Traffic Accident CCTV

This dataset is a 128-image subset of the [Traffic Accident CCTV Object Detection](https://huggingface.co/datasets/justjuu/traffic-accident-cctv-object-detection) dataset hosted on Hugging Face.

## About the source dataset

The source dataset contains CCTV footage frames captured from traffic cameras, annotated for object detection tasks. It covers scenes of traffic accidents and surrounding road activity, with bounding box labels for vehicles, pedestrians, and other relevant objects. It is intended for training and evaluating object detection models in real-world traffic surveillance scenarios.

## This subset

The `train/` folder contains 128 images sampled from the source dataset's training split.
